# 项目文档

`docs` 用于保存团支书 AI 助手的产品方案、技术设计、功能规格和 README 页面截图。

## 目录说明

```text
docs/
├── assets/
│   └── readme/             # GitHub 项目主页使用的真实界面截图
├── superpowers/
│   └── specs/              # 已确认功能的设计规格
└── 团支书AI助手第二阶段本地开发方案.md
                             # 项目产品范围与本地开发方案
```

## 文档用途

- `assets/readme` 中的图片必须来自当前可运行项目，并且不包含 API Key、Token 或个人敏感信息。
- `superpowers/specs` 记录已经确认的功能设计，便于实现、回归和后续迭代。
- 根目录 [README](../README.md) 是项目对外的总体入口，这里保存更详细的设计资料。
